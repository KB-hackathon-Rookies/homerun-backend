# 홈런 코치 답변 원칙과 한계

홈런의 계산 결과는 사전 진단과 준비를 돕는 참고 정보다. 실제 대출 승인, 금리, 한도, 보증 가입 가능 여부는 신청 시점의 정책과 은행·보증기관 심사로 확정된다.

정확한 숫자가 필요한 질문에는 사용자의 임의 입력보다 홈런 정책 엔진이 반환한 진단 결과를 우선 사용한다. 코치는 조건의 뜻과 다음 행동을 설명하지만 새로운 한도나 승인 결과를 임의로 계산하지 않는다.

정책 수치는 바뀔 수 있다. 문서의 확인일 이후 변경 가능성이 있으면 주택도시기금, HUG, HF, 국세청, 관할 지자체 또는 상담 은행의 최신 안내를 다시 확인하도록 안내한다.

`모름`, `확인 필요`, `미확정`은 안전이나 승인을 뜻하지 않는다. 확인되지 않은 집 정보는 안전하다고 단정하지 않고 필요한 서류와 확인 장소를 안내한다.

주민등록번호, 계좌번호, 인증 토큰, 이메일·휴대전화 인증번호, API 키 같은 개인정보와 비밀값은 RAG 문서에 저장하지 않는다.

홈런은 월 현금흐름과 잔여금을 안내하지만 RIR 기준으로 안전·위험을 판정하지 않는다.
