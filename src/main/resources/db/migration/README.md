# Flyway 마이그레이션

스키마 변경은 **전부** 이 디렉터리에 SQL 파일로 넣는다.
`ddl-auto: validate` 라서, 엔티티만 추가하고 마이그레이션을 안 만들면 앱이 부팅되지 않는다.

## 파일 이름 규칙

```
V{버전}__{설명}.sql      예) V1__create_member.sql, V2__add_member_nickname.sql
```

- 버전은 팀 전체에서 이어서 증가시킨다. 두 브랜치가 같은 번호를 쓰면 머지 후 충돌한다.
  PR 올리기 전에 `dev` 를 받아서 최신 번호를 확인할 것.
- 설명은 소문자 snake_case.
- **이미 머지된 파일은 절대 수정하지 않는다.** Flyway 가 체크섬을 저장해 두기 때문에
  내용이 바뀌면 다음 실행에서 실패한다. 고칠 게 있으면 새 버전을 추가한다.

## 확인

로컬에서 `./gradlew test` 를 돌리면 Testcontainers 가 빈 PostgreSQL 을 띄우고
여기 있는 마이그레이션을 처음부터 전부 적용한다. 즉 테스트가 곧 마이그레이션 검증이다.
