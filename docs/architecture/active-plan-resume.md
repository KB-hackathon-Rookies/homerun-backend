# 로그인 후 계획 이어하기

로그인 사용자는 `GET /api/v1/plans`로 자신의 계획만 최근 활동 순으로 조회한다. 응답에는 현재 단계,
마지막으로 방문한 단계와 화면 위치, 규칙 버전, 단계별 상태가 포함된다.

`GET /api/v1/plans/active`는 `ACTIVE` 상태 중 가장 최근에 변경된 계획 하나를 반환한다. 프론트는 이
응답의 `lastVisitedStage`와 `lastLocationCode`를 이용해 마지막 화면에서 이어간다. 진행 중인 계획이
없으면 `PLAN_022`를 반환하므로 새 계획 생성 화면으로 이동할 수 있다.

목록과 이어하기 쿼리는 모두 `memberId`를 조건으로 사용한다. 다른 회원의 계획 ID를 받아 필터링하는
방식이 아니므로 타인의 계획이 목록이나 이어하기 응답에 섞이지 않는다.
